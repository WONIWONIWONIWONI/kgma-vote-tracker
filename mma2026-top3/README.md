# MMA2026 TOP 3 — 원본 연결 미완료

대상: https://www.melon.com/mma/2026/vote/top10/

상위 3팀용 트래커 화면, 실제 관측값 검증, 팀 ID별 추이, 순위 간 표차, 캔들차트, 직전 관측 대비 변화, KST 시간대별 증가량, CSV와 박스별 PNG를 구현한 준비본입니다. 원본 결과를 수집한 기록은 **0건**입니다. 실시간 운영·배포 완료를 뜻하지 않습니다.

이 작업 환경에서 멜론 직접 요청은 네트워크 접근 정책으로 거절됐으며, 웹 조회도 대상 페이지를 불러오지 못했습니다. 공식 응답의 필드·인증 여부·갱신 주기를 확인하지 못했으므로 임의 API를 만들거나 과거 투표 자료를 채우지 않았습니다. 실제 수집 요청을 수행하는 워크플로는 추가하지 않았습니다.

`dist/`는 별도 빌드 없이 정적 서버에서 열 수 있습니다. `dist/data/history.json`에 원본에서 검증한 관측 기록을 연결하면 화면이 동작합니다. `sourceAt`은 원본이 제공한 집계 시각이며 제공되지 않으면 null, `observedAt`은 실제로 읽은 시각입니다. 이를 서로 바꾸어 기록하면 안 됩니다. `totalVotes`는 전체 후보의 득표 합계이고 상위 세 팀의 합이나 투표 참여자 수로 대신하지 않습니다. 원본 점유율의 분모가 이 값과 다르면 수집 계약과 화면을 함께 조정해야 합니다.

실제 조회 경로를 확인한 뒤 수집 어댑터를 구현하고, 원본과 대조한 첫 관측값을 저장한 후에 게시해야 합니다. 기존 KGMA 사이트와 데이터에는 변경이 없습니다. 시험용 값은 테스트 프로세스 안에서만 사용하며 배포 데이터에는 포함하지 않습니다.

검사: `node --test tests/model.test.cjs`, `node --check dist/app.js`.
